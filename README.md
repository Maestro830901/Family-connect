# 🏠 Family Connect

Eine zweisprachige (Deutsch / Polnisch) Web-Anwendung für Familien zur einfachen Koordination von Arbeitszeiten, Terminen, Aufgaben und Tagesfotos.

## 🌟 Hauptfunktionen
- 🗓️ **Arbeits- & Terminplaner:** Gegenüberstellung von Schichtzeiten (Eltern) sowie Schul- und Arztterminen (Kinder).
- 📝 **Familien-To-Do-Liste:** Aufgaben gezielt einzelnen Personen (Mama, Papa, Kinder, Großeltern) oder allen zuweisen.
- 📸 **Foto des Tages:** Eigenes Tagesfoto hochladen oder automatische Galerie-Diashow abspielen.
- 🌐 **Zweisprachig:** Umstellung der gesamten App per Klick zwischen Deutsch 🇩🇪 und Polnisch 🇵🇱.
- 👥 **Mitglieder-Einladung:** Generierung von Codes für Kinder und Großeltern.

## 🚀 Nutzung
Die Anwendung läuft direkt im Browser und ist für Smartphones, Tablets und Desktop-PCs optimiert.
